# 본과 1학년 (웹앱 껍데기)

로그인 화면과 홈 화면 아이콘만 있는 공개 저장소입니다. 시간표·후기·기출 같은 내용은 여기 없고,
초대받은 사람이 GitHub로 로그인하면 비공개 저장소에서 앱 본체를 읽어 옵니다.

- `config.js` — Supabase 주소와 공개 키(anon key). 공개돼도 되는 값입니다.
- `shell.js` — 로그인, 회원 확인, 본체 불러오기, 저장 공간 연결
- `manifest.webmanifest`, `sw.js`, `icons/` — 홈 화면에 추가했을 때 앱처럼 열리게
- `CNAME` — 내 도메인
